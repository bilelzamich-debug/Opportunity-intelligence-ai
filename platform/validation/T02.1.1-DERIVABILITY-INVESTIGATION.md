## 5. Proof of underdetermination

**Definition.** A specification *determines* X iff exactly one X satisfies it.

**Formalisation.** A taxonomy is a pair `T = (M, c)` where `M` is a finite
member set and `c : Source → M` a total classifier.

**Constraint evaluation.** Every ratified constraint mentioning source types
uses them in exactly one way — to COUNT or to PARTITION:

| Constraint | Requires | Needs member identity? |
|---|---|---|
| N-03 coverage | `\|{c(s) : s acquired}\| / \|M\|` | No |
| S-02 input 2 | `\|{c(s) : s ∈ lineage}\|` | No |
| S-05 stratification | a partition of Facts by `c(source)` | No |
| N-16 Tier 2 | the multiset `{c(s)}` | No |

Every constraint is therefore satisfied by **any** `(M, c)` with `|M| ≥ 1` and
`c` total.

**Witnesses.** Three taxonomies, each satisfying all four constraints:

| | `M` | Interpretation |
|---|---|---|
| `T₁` | `{EXTERNAL}` | all sources one type |
| `T₂` | `{HUMAN_AUTHORED, MACHINE_GENERATED}` | partition by authorship |
| `T₃` | `{A, B, C, D}` | any 4-way partition |

All are evaluable under N-03, S-02, S-05 and N-16. They are pairwise
non-isomorphic (`|M|` = 1, 2, 4).

**Discrimination test.** Searched for any ratified predicate that would
separate the witnesses — `at least n source types`, `minimum of n source
types`, `exactly n source types`, `source types must include/contain`,
`source types shall`. Result: **NONE**.

**Therefore** ≥ 3 distinct models satisfy the ratified theory, and no ratified
statement discriminates among them. The architecture does not determine the
taxonomy. **∎**

**Corollary.** `T₁ = {EXTERNAL}` is constraint-satisfying yet renders S-02
property P3 ("*n* sources of one type yield less than *n* across types")
vacuous — diversity would be constant at 1. A ratified property becomes inert
under a constraint-satisfying model, which independently confirms that the
constraints do not pin the intended model.

## 8. Can T02.1.1 legally continue?

**No.**

The backlog's own field definitions (§0.3) state: **"Acceptance criteria |
**Binding** conditions for completion."** T02.1.1 declares three. AC1 requires
`source_type` drawn from a **closed taxonomy**; §5 proves no closed taxonomy is
derivable. AC3 requires a learnable P8 target; IOM §3.9 designates M-02
**blocking**.

Completing T02.1.1 would require selecting one witness from `{T₁, T₂, T₃, …}`.
That selection is:

- an architectural decision — **Playbook F2** ("Making an architectural
  decision yourself");
- closure of a marker by implementation — **Playbook F3** and
  `decisions/README` L145 ("a marker is closed only by a record in this
  register");
- and, because four ratified decisions already depend on the choice, a
  decision with register-wide consequences.

T02.1.1's `Independent: Yes` means only "can be picked up standalone once
dependencies are met" (§0.3). Its *task* dependency `T01.8.1` is met; its
*specification* dependency M-16 is not, and the backlog has no field for that
class of dependency — which is precisely why the task reads as actionable.

**Legal status:** T02.1.1 may remain open with its implementable portion
delivered (registry, versioned trust storage, N-16 independence — all fail
closed elsewhere). It **cannot be marked complete**. AC1 and AC3 are
unsatisfiable without a new ratified decision.
