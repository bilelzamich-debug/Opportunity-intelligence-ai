# Templates

| File | Use |
|---|---|
| [`DECISION-RECORD-TEMPLATE.md`](DECISION-RECORD-TEMPLATE.md) | Every new decision record |
| [`COMPLETION-REPORT-TEMPLATE.md`](COMPLETION-REPORT-TEMPLATE.md) | Task completion (11 sections) |
| [`EXIT-GATE-REPORT-TEMPLATE.md`](EXIT-GATE-REPORT-TEMPLATE.md) | Phase closure (11 sections) |
| [`../.github/PULL_REQUEST_TEMPLATE.md`](../.github/PULL_REQUEST_TEMPLATE.md) | Pull requests |

All three report templates require an **Honest Limitations** section naming the
weakest point in the work. That is Constitution Article X applied to the
project's own reporting.
