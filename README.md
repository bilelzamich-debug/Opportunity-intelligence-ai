## Why Rejected Alternatives Are Preserved

`DECISION-TEMPLATE.md`:

> **Field 2 is the field most often skipped and the one that matters most.**
> MISSING-50 exists precisely because v1 recorded decisions without
> alternatives. *A decision without rejected alternatives is a preference.*

M-50 — v1's four architecture decisions recorded as bare titles — is the
project's founding defect. Nobody could tell a considered constraint from an
unexamined default. This directory exists so that failure is not repeated.
